# exercism

Solutions and exercises completed on [Exercism](https://exercism.org/).

## Repository structure

Track-specific exercise solutions are organized into directories, one per Exercism language track.

## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/PaulaHara/exercism.git
   cd exercism
   ```

2. Choose an exercise directory and follow the instructions for that language track to run or test it.

## Contributing

This repository contains personal exercise solutions. Suggestions and improvements are welcome through GitHub issues or pull requests.
